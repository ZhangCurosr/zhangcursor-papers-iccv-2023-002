# 论文速读：The-Perils-of-Learning-From-Unlabeled-Data-Backdoor-Attacks

## 一句话总结
本文首次系统揭示了半监督学习（SSL）因依赖未检验未标记数据而面临的严重后门投毒风险，提出了一种仅需污染0.2%未标记样本的弱对抗者clean-label攻击。该攻击利用SSL的伪标签自反馈机制，在5种主流SSL算法和4个基准数据集上实现超过80%的后门成功率，并能绕过现有多种SOTA防御。

## 研究问题与动机
1. **SSL的安全盲区**：SSL的核心优势是低成本利用海量未标记数据，但现有后门攻击研究几乎全部聚焦于监督学习，未评估“未检查数据”引入的投毒威胁。
2. **对抗者能力假设脱离实际**：传统投毒攻击要求强对抗者掌握模型参数、训练数据分布或算法细节，而SSL实际场景中对抗者仅能接触互联网爬取的原始未标记数据，此类弱对抗威胁未被建模。
3. **现有攻击在SSL上全面失效**：预处理评估显示DeHiB、CL-Badnets、Narcissus等SOTA攻击在SSL上的ASR均接近0%，主要原因是现代SSL普遍采用的强增强（Cutout、RandAugment等）破坏了动态或局部触发器。
4. **防御机制错位**：当前后门防御主要针对监督学习的数据/模型后处理设计，缺乏针对“未标记数据投毒”这一SSL特有攻击面的有效防护方案。

## 核心贡献（创新点）
1. **提出面向SSL的弱对抗者后门攻击框架**：仅需注入0.2%的未标记污染数据即可植入后门，打破了现有攻击对强信息假设的依赖。
2. **提炼三条触发器设计经验法则**：通过系统失败归因，总结出SSL后门攻击必须满足的目标类clean-label、全屏覆盖、抗噪重复模式三个必要条件。
3. **设计静态重复网格触发器并验证强泛化性**：采用固定参数（强度$\alpha$、间隙$g$、宽度$w$）的简单网格图案，在CIFAR10/100、SVHN、STL10及MixMatch/ReMixMatch/UDA/FixMatch/FlexMatch上均取得ASR>80%的效果。
4. **系统性验证现有防御的失效边界**：测试Fine-tuning、Neural Attention Distillation、Strip、Anti-backdoor Learning等5种防御，证明其在未标记数据投毒场景下要么大幅牺牲干净准确率，要么完全无效。

## 方法详解
- **威胁模型**：对抗者可向未标记数据集$D^u$中插入恶意样本，但无法访问标记数据$D^l$、模型架构或训练代码，仅知晓分类任务类别数。
- **攻击机理（伪标签自反馈 exploitation）**：以FixMatch为例，模型$f_\theta$初始通过标记数据学习特征，随后为未标记数据生成高置信度伪标签进行二次训练。攻击者从目标类$y^t$分布中选取样本$x$，附加静态触发器$T$得到$X^p = X^{y^t} + T$并混入$D^u$。训练初期$f_\theta$因保留原始语义而正确赋予伪标签$y^t$；随着训练推进，所有$X^p$共享同一简单触发器，模型被强制将$T$与$y^t$绑定，从而完成后门植入。
- **触发器设计**：全图像尺寸的静态重复网格，参数为像素强度$\alpha$（0~255）、相邻亮区间隙$g$、亮区宽度$w$。全屏设计抵御Cutout/Cutmix遮挡；重复结构抵御RandAugment随机噪声。
- **损失函数**：攻击不修改SSL原有联合损失（监督交叉熵$\mathcal{L}_l$ + 无监督伪标签/一致性损失$\mathcal{L}_u$），仅通过构造满足上述条件的污染样本被动改变训练动态，属于被动投毒范式。

## 实验与结果
- **数据集与基线**：CIFAR10、CIFAR100、SVHN、STL10；对比基线包括DeHiB、CL-Badnets、Narcissus；评估模型为MixMatch、ReMixMatch、UDA、FixMatch、FlexMatch。
- **核心指标**：ASR（后门成功率）、CA（干净准确率）、TA（目标类准确率）、$L_\infty$范数（触发器可见性）。
- **主要结果**：仅污染0.2%训练数据时，本文攻击在所有组合上ASR均超80%（CIFAR100部分达90%+）；CA下降<1.5%，TA下降<3%；$L_\infty$扰动仅为30/255，隐蔽性优于所有基线。
- **最强结果**：CIFAR10 + FixMatch以0.2%污染率实现96.8% ASR，CA保持93.5%；UDA + CIFAR10仅用0.1%污染即达81.5% ASR。
- **防御对抗**：NAD表现相对最佳（FixMatch/ReMixMatch ASR分别下降约22%/23%），但最终ASR仍>60%；FT/FP严重损害CA；ABL因强增强使无监督损失与干净样本无异而完全失效；Strip对高ASR有效但对中等ASR（80%~90%）漏检率高。

## 相关工作脉络
1. **DeHiB [48]**：首个SSL后门攻击，但假设对抗者拥有标记数据$D^l$访问权限；本文证明其在无$D^l$设定下ASR≈0%，凸显威胁模型差异。
2. **CL-Badnets [50] / Narcissus [50]**：监督学习clean-label攻击，依赖动态或样本特定触发器；被SSL强增强轻易破坏，本文由此归纳出全屏+重复模式的必要性。
3. **FixMatch [40] / ReMixMatch [2]**：伪标签与一致性正则的代表性工作；本文揭示其自反馈机制是后门植入的“放大器”，而非天然防御。
4. **NAD [24] / Strip [17] / ABL [25]**：主流后门防御；本文系统验证其在未标记数据投毒场景下的失效机理，指出防御重心需前移至数据预处理。
5. **Carlini [5]**：早期探讨未标记数据集投毒，但未形成可实际部署的后门攻击框架；本文将其思路形式化为满足严格设计约束的触发器攻击。

## 局限性与未来方向
- **局限性**：攻击效果受目标类固有可分性影响（部分简单特征类别ASR偏低）；污染比例极端（过小或过大）时攻击效能下降；未在视频、音频或多模态SSL场景验证。
- **未来方向**：① 设计针对未标记数据的自动检测/清洗流水线（如频域异常检测、触发器模式过滤）；② 探索“由设计即鲁棒”的SSL架构，从根本上消除对未检查数据的依赖；③ 将攻击框架迁移至自监督学习（如SimCLR）等同样依赖强增强的范式。

## 研究启发与可借鉴点
1. **失败归因驱动的攻击设计**：从现有攻击在目标范式上的系统性失效中提炼设计约束（三条准则），是构建新攻击的高效路径，可复用于联邦学习、自监督学习等新兴范式的攻击研究。
2. **静态触发器的隐蔽-鲁棒权衡**：全屏重复网格以极小$L_\infty$扰动换取对强增强的抵抗力，证明了“简单模式+充分覆盖”比复杂动态触发器更适合现代数据增强密集的learning pipeline。
3. **防御前置化思路**：本文证明后处理防御对SSL无效，提示团队可在数据入库阶段引入轻量级异常检测模块（如基于频率统计、聚类离群点或触发器模式匹配），作为SSL管线的安全前置步骤。
4. **标准化评估协议**：采用ASR/CA/TA/$L_\infty$四维指标并严格控制污染比例（0.2%），为后续SSL安全性基准测试提供了可直接复用的评测模板。

## 关键术语表
- **Semi-supervised Learning (SSL)**：结合少量高质量标记数据与大量低成本未标记数据提升模型性能的学习范式。
- **Pseudo-labeling**：SSL核心机制，利用当前模型对未标记数据的高置信度预测作为伪标签参与后续训练。
- **Clean-label Attack**：仅篡改输入特征而不修改真实标签的后门攻击类型，难以通过标签异常检测发现。
- **Backdoor Trigger**：嵌入输入中的特定图案或扰动，触发后门使模型在带触发器时输出预设目标类别。
