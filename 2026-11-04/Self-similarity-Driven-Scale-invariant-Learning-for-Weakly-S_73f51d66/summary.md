# 论文速读：Self-similarity-Driven-Scale-invariant-Learning-for-Weakly-S

## 一句话总结
本文针对弱监督行人搜索任务中因拍摄距离与视角差异导致的**尺度变化瓶颈**，提出端到端的自相似度驱动尺度不变学习框架（SSL），通过多尺度样本分支与动量记忆库辅助的指数动态伪标签策略，在仅依赖边界框标注的条件下实现了跨尺度特征一致性与高判别匹配性能。

## 研究问题与动机
1. **尺度变化是弱监督行人搜索的核心盲区**：现有方法多聚焦于利用行人间特征关系生成伪标签，但忽视了同一行人在不同距离/视角下图像尺度差异巨大这一更严重的障碍。
2. **小尺度图像信息匮乏影响伪标签质量**：低分辨率裁剪图包含的行人类细节少，导致下游特征提取不稳定，进而使伪标签预测准确率下降。
3. **跨尺度相似度度量困难**：同一人的跨尺度图像特征分布差异显著，而一步法（one-step）无法像两步法那样自由调整输入分辨率，进一步加剧匹配难度。
4. **静态阈值伪标签生成的固有过拟合/欠召回问题**：固定相似度阈值要么遗漏难正样本（阈值过高），要么引入大量噪声标签（阈值过低），难以自适应训练进程。

## 核心贡献（创新点）
1. 提出端到端 SSL 框架，利用多尺度样本分支引导主分支学习尺度不变特征。**与已有工作的本质区别在于**：现有弱监督方法（如 R-SiamNet、CGPS）主要挖掘行人间视觉关系或上下文线索，本文首次将“自相似度先验”显式引入一步法，直接针对尺度变化这一底层障碍进行优化。
2. 设计基于硬样本挖掘与前景掩码过滤的尺度不变损失（SL）。**与已有工作的本质区别在于**：不同于普通多尺度数据增强或固定度量损失，该损失显式最小化 query 与 hardest positive 的距离、最大化与 hardest negative 的距离，并附加原始尺度对齐正则，在特征空间内强制建立跨尺度几何一致性。
3. 提出指数衰减动态多标签学习（DML）与双分支动量记忆库。**与已有工作的本质区别在于**：区别于无监督 Re-ID 中常用的聚类算法或固定阈值伪标签，该策略将标签生成建模为随 epoch 指数平滑下降的动态分类过程，并融合主干与多尺度分支的 EMA 特征记忆，实现标签质量与判别特征的联合渐进优化。

## 方法详解
- **整体流水线**：基于 Faster R-CNN 构建主分支进行行人检测与实例特征提取（Deformable RoI Pooling）；新增多尺度样本分支用于提供尺度监督信号。推理阶段仅启用主分支，多尺度分支与记忆库完全关闭，无额外开销。
- **尺度增强与前景过滤**：利用 GT 边界框裁剪行人，并通过二进制掩码滤除背景；再经双线性插值缩放至 $K$ 个固定尺度（训练前在训练集 GT 框上执行 k-means 聚类自动选定尺度）。
- **尺度不变损失（$L_{scale}$）**：采用对比形式，对 mini-batch 内每个 query 行人 $i$：
  $L_{scale}^{b,i} = [\max_{s} D(f_i, f_i^s) - \min_{j\neq i, s} D(f_i, f_j^s)]_+ + \gamma D(f_i, f_i^o)$
  其中 $D(\cdot)$ 为平方欧氏距离，$f_i$ 为主分支实例特征，$f_i^s$ 为多尺度分支的第 $s$ 尺度特征，$f_i^o$ 为原始尺度特征。该损失同时拉近 hardest 正例、推远 hardest 负例，并约束原始尺度特征与实例特征对齐以聚焦人体主体。
- **动量记忆库与尺度增强特征**：维护 $\mathcal{M}_M \in \mathbb{R}^{N\times d}$（多尺度分支特征均值）与 $\mathcal{M}_I \in \mathbb{R}^{N\times d}$（主分支特征）两个 EMA 更新库（$\lambda=0.8$），融合得到 $\mathcal{M} = \text{mean}(\mathcal{M}_M, \mathcal{M}_I)$ 用于后续伪标签生成。
- **动态多标签学习（$L_{DML}$）**：将伪标签生成视为 $N$ 类多标签分类。基于 $\mathcal{M}$ 计算相似度矩阵 $S=\mathcal{M}\mathcal{M}^T$，采用指数衰减阈值 $t = t_b + \alpha \cdot e^{\beta \cdot e}$ 生成二值标签 $Y$；同时引入“同图不同人”先验，对排序后的相似列表强制置零冲突标签。最终联合优化主分支与多尺度分支的多标签交叉损失 $L_{DML}$。
- **总目标函数**：$L = L_{scale} + L_{DML} + L_{det}$，端到端联合优化。

## 实验与结果
- **数据集与评估**：PRW 与 CUHK-SYSU，指标为 mAP 与 Top-1 CMC（gallery size=100）。骨干为 ImageNet 预训练 ResNet50，batch size=4，SGD 优化 26 epoch，初始 lr=0.001，在 16 与 22 epoch 各衰减 10 倍。
- **消融结果（PRW）**：Baseline 得 13.0% mAP / 63.8% Top-1；加入 DML 提升至 16.8% / 66.9%；加入 SL 跃升至 27.4% / 81.4%；两者结合达到 **33.9% / 82.7%**。多尺度设置中，Multi-Scale + 背景过滤最优（33.9% / 82.7%），单尺度仅提升 0.7%。
- **SOTA 对比**：在 PRW 上大幅领先 CGPS（16.2% / 68.0%）与 R-SiamNet（21.2% / 73.4%）；在 CUHK-SYSU 上达到 **87.6% mAP / 89.0% Top-1**，超越当前最强弱监督方法 R-SiamNet 1.6% / 1.9%，且部分指标超越 SeqNet、CTG 等全监督基线。
- **可视化分析**：t-SNE 显示不同尺度（圆/方/叉标记）的同行者特征簇明显更紧凑；检索可视化验证了模型在跨尺度与混淆样本下的强匹配能力。
