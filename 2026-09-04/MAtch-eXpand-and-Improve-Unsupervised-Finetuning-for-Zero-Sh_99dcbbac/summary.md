# 论文速读：MAtch-eXpand-and-Improve-Unsupervised-Finetuning-for-Zero-Shot-Action-Recognition-with-Language-Knowledge

## 一句话总结
本文提出MAXI方法，利用无标签视频集合与多源语言知识（动作词典、LLM、VL模型）构建文本袋，通过多实例学习（MIL）无监督微调CLIP，显著提升零样本/少样本动作识别性能，在多个基准上超越全监督基线。

## 研究问题与动机
- **VL模型存在动作表征偏差**：CLIP等大规模视觉-语言模型倾向于过度表征物体（名词），对动作（动词/动词短语）关注不足，导致零样本动作识别性能受限。
- **已有方法依赖全量标注数据**：现有视频微调方法需依赖大规模全标注数据集（如K400），标注成本高且暴露给模型的词汇总量有限（仅400类），限制了零样本泛化能力。
- **缺乏对无标签视频的利用**：实际场景中往往拥有海量无标注视频资源，但如何有效利用这些无标签数据增强VL模型的动作理解能力尚未被充分探索。
- **语言知识的协同利用不足**：Fine-tuning阶段仅使用简单动作名称作为文本，未充分利用大型语言模型（LLM）和世界知识来扩展动作描述。

## 核心贡献（创新点）
- **无监督视频微调框架MAXI**：首次提出利用无标签视频集合和语言来源进行CLIP微调的方法，无需任何 ground truth 标注。
- **多源语言知识驱动的文本袋构建**：通过CLIP匹配、GPT-3文本扩展、BLIP视频字幕三类语言源构建每个视频的文本袋，实现细粒度的动作语义对齐。
- **改进的MIL-NCE损失函数**：在标准MIL-NCE基础上引入"最佳匹配文本一致性"约束，鼓励具有相同最佳匹配文本的视频及其文本袋在特征空间聚集。
- **系统性的实验验证**：在7个完全未见过的零样本/少样本动作识别基准上验证，相比原始CLIP最高提升14%，并在部分任务上超越全监督ViFi-CLIP。

## 方法详解
**整体流程**：给定无标签视频集合V和预定义动作词典D，为每个视频构建文本袋，然后通过MIL进行CLIP微调。

**CLIP视频编码器适配**：
- 采用ViFi-CLIP的帧级处理范式，从视频中采样M帧并通过视觉编码器提取特征，取平均作为视频表示：$z_v = \sum_m \phi_v(x_m^F; \theta_v) / M$
- 保留CLIP图像编码器参数，不引入随机初始化的可学习参数，利于直接迁移预训练知识。

**文本袋构建（三步）**：
1. **CLIP匹配**：计算视频与词典D中所有文本的余弦相似度，选取Top-1匹配文本$\hat{t}_i = \arg\max_{t \in D} \text{sim}(\phi_v(x_i), \phi_t(t))$，加入文本袋$T_i$。此步骤起到知识蒸馏作用，防止在小域上过拟合。
2. **GPT-3文本扩展**：以最佳匹配文本$\hat{t}_i$为指令，利用GPT-3的世界知识生成扩展动作描述，提取其中的动词和动词短语（包含lemma和gerund形式），加入文本袋。
3. **BLIP视频字幕扩展**：用BLIP对视频帧生成图像描述，从中提取动词和动词短语，加入文本袋。
4. **文本袋过滤**：设置相似度阈值$\delta_p$，保留相似度排名前$p\%$的视频及其文本袋，以提升训练质量。

**多实例学习损失函数**：
- 每轮训练随机采样$N_{bag}$个文本构成固定大小的文本袋$T_i = \{t_{i,n}\}_{n=1}^{N_{bag}}$
- 提出的损失函数：
$$\mathcal{L} = -\frac{1}{|I_B|} \sum_i \log \frac{\sum_j \sum_n \exp(\bar{\phi}_v(x_i)^\top \bar{\phi}_t(t_{j,n})/\sigma) \cdot \mathbb{1}(\hat{t}_i = \hat{t}_j)}{\sum_k \sum_n \exp(\bar{\phi}_v(x_i)^\top \bar{\phi}_t(t_{k,n})/\sigma)}$$
- 分子中的指示函数$\mathbb{1}(\hat{t}_i = \hat{t}_j)$鼓励具有相同最佳匹配文本的视频及其文本袋靠近，形成语义一致的分组。

**推理策略**：线性权重空间集成（original CLIP权重比例0.2）+ 单视图采样。

## 实验与结果
**数据集与设置**：
- 微调数据：无标签Kinetics 400（K400），约24万视频
- 评估基准：UCF101、HMDB51、Kinetics600（K600）、Charades、Moments-in-Time（MiT）、MiniSSv2、UAV Human
- 评估协议：UCF/HMDB/K600/MiniSSv2/UAV采用Top1/Top5准确率，Charades和MiT采用mAP
- 实现细节：ViT-B/16编码器，温度$\sigma=0.02$，学习率$5\times10^{-6}$，batch size 256，训练10轮，采样16帧

**主要结果**：
- **UCF101**：MAXI (K400 dict + GPT3 + BLIP verbs) 达到78.2% Top1，超越ViFi-CLIP (76.8%) 1.4个百分点
- **HMDB51**：MAXI达到52.2% Top1，超越ViFi-CLIP (51.3%)
- **K600**：MAXI达到71.6% Top1和92.5% Top5，超越ViFi-CLIP (71.2% Top1, 92.2% Top5)
- **跨域大偏移数据集**：在MiT和MiniSSv2上超越全监督ViFi-CLIP，分别达到22.91/46.38和6.37/18.73
- **少样本学习**：以MAXI预训练权重为初始化，在2-shot HMDB上达到58.0%，超越ViFi-CLIP全监督预训练 (55.8%)

**关键提升幅度**：相比原始CLIP，MAXI在多个基准上实现最高约14%的绝对性能提升。

## 相关工作脉络
- **ViFi-CLIP [38]**：本文遵循其帧级处理+特征池化的视频适配范式，但ViFi-CLIP使用全监督标注进行微调，而MAXI完全无监督。
- **XCLIP [33] / Action-CLIP [47]**：通过引入额外时空建模组件适配CLIP用于视频，同样依赖全监督标注；MAXI不引入可学习时空模块，仅通过文本信息增强语义对齐。
- **ER-ZSAR [7] / JigsawNet [34]**：依赖人工校正的动作描述和ground truth标注进行训练，需要大量人力成本；MAXI无需任何标注。
- **BLIP [23]**：提供视频到文本的跨模态生成能力，本文将其用于视频字幕扩展以获取动作相关动词。
- **GPT-3 [3]**：提供大规模语言知识，本文通过提示工程将其扩展为动作描述，丰富文本袋内容。
- **MIL-NCE [31]**：多实例学习对比损失的基础，本文在此基础上引入了"最佳匹配文本一致性"约束。

## 局限性与未来方向
- **词典依赖**：方法需要预定义的粗糙动作词典作为先验，虽然实验证明了其对噪声词典的鲁棒性，但在完全没有领域知识的场景下效果未知。
- **GPT-3/BLIP依赖**：文本袋构建依赖外部大模型，推理成本较高，且生成内容的质量可能影响最终效果。
- **未探索长视频**：当前仅在16/32帧采样下评估，对于更长视频或细粒度时序动作的理解能力有待验证。
- **单一 VL backbone**：仅验证了CLIP，对其他VL模型（如BLIP-2、LLaVA等）的泛化性未讨论。
- **未来方向**：可扩展至其他视频理解任务（如视频检索、视频-语言推理），探索更高效的文本生成策略，以及结合时序建模增强动态动作理解。

## 研究启发与可借鉴点
- **无监督文本袋构建范式**：利用多源语言知识（词典+LLM+VL模型）构建 noisy text bag 的思路可迁移到其他模态对齐任务，如无监督视频-语言预训练。
- **MIL+NCE的改进设计**：在对比学习框架中引入"一致性约束"（相同最佳匹配文本的视频聚集）是一种有效的正则化手段，可推广到其他多实例学习场景。
- **知识蒸馏防止过拟合**：保留原始CLIP作为匹配教师、通过加权集成（ratio 0.2）保持预训练知识，这一策略对小型数据集上的微调具有普适参考价值。
- **动词增强的语义对齐**：实验表明注入动词比注入名词更有效，提示我们在动作理解任务中应重点关注谓词表征，可为其他时序理解任务的设计提供启发。
- **低成本评估协议**：通过 filtering ratio p 控制训练数据质量而非数量，展示了在数据效率与模型性能之间的权衡策略，适用于资源受限场景。

## 关键术语表
**Vision-Language (VL) 模型**：通过大规模图像-文本对预训练，实现视觉和语言表征对齐的模型，如CLIP、ALIGN。
**Zero-shot Action Recognition**：在训练阶段未见过任何测试类别样本的情况下，识别视频中的动作类别。
**Text Bag**：通过多种语言源为单个视频构建的文本集合，包含潜在匹配的多个动作描述。
**Multiple Instance Learning (MIL)**：一种弱监督学习范式，假设一个包（bag）中至少有一个实例为正，本文用于处理文本袋中的噪声。
**MIL-NCE Loss**：结合多实例学习与噪声对比估计的损失函数，软性关联视频与其文本袋中的所有文本。
**Kinetics 400 (K400)**：包含约24万视频、400个动作类别的大规模动作识别数据集。
**Fine-tuning**：在预训练模型基础上，利用新数据进行进一步训练以适应特定任务。
**Template Prompt**：CLIP中使用的手写模板，如"a photo of a {action}"，用于生成文本特征。
